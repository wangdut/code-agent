# Code Agent

基于大语言模型的 VSCode 智能编程 Agent 插件。支持代码生成、文件编辑、终端执行、多轮任务自主闭环，对标 Qoder、Cline (Claude Dev)、CodeX 等主流 AI 编程插件。

**作者**：wangh
**版本**：1.4.5

## 功能特性

### 多模型接入
- 适配器设计模式封装模型调用层，兼容 OpenAI 协议的所有模型服务，任意合规接口填写 Base URL 即可接入
- 预置主流厂商官方配置：DeepSeek、智谱 AI、月之暗面 Kimi、通义千问、字节跳动豆包、OpenAI、Anthropic，新增服务商时下拉快捷选择自动填充名称与官方 Base URL，也可手动输入自定义地址（兼容私有化部署/自定义代理）
- 服务商体系管理：服务商级增/删/改（名称 + Base URL 必填、API Key 选填），预置 DeepSeek 服务商开箱即用（不可删除、可编辑）；API Key 按服务商独立存储于系统密钥库（SecretStorage），不写入任何项目文件与持久化数据
- 模型列表动态拉取 + 兜底保障：基于服务商 Base URL 调 `/models` 接口自动获取模型列表（启动增量同步、服务商增改后自动拉取、设置页手动刷新）；无密钥时以预置厂商官方标准模型列表兜底，配置密钥后动态拉取自动覆盖兜底数据
- 本地缓存与元数据兜底：拉取结果持久化到本地缓存，离线或接口异常自动使用缓存；未返回元数据的模型统一按 300K 上下文窗口 / 100K 最大输出兜底；用户手动校准的模型元数据重新拉取时按模型 ID 合并保留
- 拉取失败精准报错：错误按场景精准拆分——Base URL 格式不合法、无法连接至接口地址、API Key 鉴权失败、接口未兼容 OpenAI 协议规范；模型拉取失败时支持勾选「仍要创建」强制完成服务商创建，手动添加模型后即可正常调用
- 密钥即时生效：密钥保存后无需重启插件即可发起对话；发起前「未配置密钥」与运行期「密钥无效/鉴权失败」两类场景严格区分提示
- 模型能力参数（上下文窗口/输出上限）与全局推理参数 `max_tokens` 语义明确区分，超限实时校验并自动截断修正
- 对话输入框底部常驻操作栏：模型切换下拉框与当前生效服务商绑定（仅展示该服务商模型，切换入口在设置页「默认服务商」）+ 模式切换下拉框

### 智能编程 Agent
- 任务规划：自主拆解执行步骤，调度工具迭代推进
- 标配工具集：文件读取、文件写入/编辑、目录遍历、代码检索、终端命令执行、diff 对比
- 多轮闭环：工具执行结果自动回传模型，自我修正直至完成
- 并行工具调度：同批次无依赖工具并行执行（连续只读工具、不同文件写入），命令类工具串行保持顺序依赖
- 流式执行流水线：只读工具参数接收完整即预启动，推理/思考与工具执行并行重叠
- 执行态可视化：流式分步执行输出——推理节点（决策结论/动作说明/结果小结）与深度思考过程分层展示，工具调用解析完整即插入执行节点（loading 态即时可见），执行结果完成后原位更新；「推理节点→深度思考→调用工具→返回结果→继续思考」按实际执行时序逐段交替，任务结束后保留完整分步执行链路可回溯
- 思考过程展示：推理模型 `reasoning_content` 全链路流式展示，每轮推理独立成段、默认展开、可折叠，永久保留可回溯；思考内容按语义单元（空行）自动分段排版，段落间隔清晰不拥挤
- 思考语言自适应：按用户提问语言动态约束思考过程与回复语言，保留技术术语原文
- 工具调用最大轮次可配置：设置页「Agent 行为」分组调整（1-1000，默认 128），即时生效；触发上限时提示文案引导调整入口

### 编辑器协作
- diff 装饰联动：文件修改完成后自动在编辑器内标记变更行（新增行左侧绿色竖线 + 浅绿背景 / 删除行左侧红色竖线 + 浅红背景，对齐 VSCode 原生 Diff 视觉）；对话框 diff 精简为「文件名 + 变更统计」节点，点击跳转编辑器定位首处变更并即时展示高亮；同一文件再次修改自动刷新为最新变更，手动关闭文件后标记自动清除
- 右键选中代码注入：编辑器右键菜单「Add to Code Agent」，将选中代码以行范围引用注入当前对话输入框，仅将对应行号范围代码加载至上下文，与 @ 全文件引用复用同一套上下文管理机制

### 渲染与交互体验
- 对话区虚拟滚动：仅渲染视口内消息，百轮长会话打开/滚动/发送均流畅
- 双层滚动体系：对话面板全局滚动 + 思考过程/工具结果/终端输出等内容子块二级滚动（统一限高，超限区块内独立滚动，滚动条对齐 VSCode 原生风格），长内容不再撑高面板
- 区块统一折叠：所有内容子块头部可折叠为单行标题条目（默认展开，折叠不影响流式更新），折叠后形成清晰执行链路列表，便于宏观把控长任务流程
- 对话滚动智能跟随：输出过程中手动拖动滚动条或滚动滚轮立即暂停自动跟随（视口稳定可自由回看历史），停止滚动操作 5 秒后平滑归位恢复实时进度展示；无干预时始终跟随最新执行节点；子块内部滚动与全局归位互不干扰
- 渲染增量更新：消息与步骤组件 memo 化，流式期间仅更新目标区块，长会话高频更新不卡顿
- 长内容默认折叠：超长代码块与超长纯文本默认折叠，点击展开全文
- Markdown 全量渲染：表格、代码块语法高亮（12+ 语言）+ 行号 + 复制按钮、深浅主题自适应
- 富文本复制：剪贴板同时写入纯文本与 Markdown 源文本，粘贴保留格式
- 会话列表：虚拟滚动（100+ 会话流畅）、右键菜单（重命名/删除）、抽屉式展开 + 拖拽调宽、点击主面板自动收起
- 服务商 API Key 密文显示 + 掩码显隐切换 + 实时配置状态反馈（按服务商独立配置）

### 上下文管理与 Token 优化
- 四层优先级架构：系统指令层 / 活跃对话层 / 历史摘要层 / 引用资源层
- 自动压缩：上下文达到模型窗口 75% 自动触发；手动压缩按钮随时可用
- 上下文动态裁剪：较早的超长历史工具输出发送前轻量降级（保留结论与关键细节），本地原文完整保留
- 差异化压缩算法：代码片段保留签名与核心逻辑，执行日志仅保留结论，对话提炼核心需求
- 压缩可回溯：生成压缩记录，支持查看压缩前完整历史
- Token 用量可视化：会话级实时进度条 + 分层占用统计 + 今日用量统计（按自然日重置）
- Token 实时统计：对话输出过程中上下文占用随流式片段实时刷新（节流 500ms，未落盘内容同步计入）；以模型返回的真实 `prompt_tokens` 校准用量，顶部栏统一「已用 X.XK / 总窗口 Y.YK」展示口径
- 用量实时累加：今日 Token 用量、消费金额与 API 调用次数随每次接口响应实时累计，与官方计费数据对齐；账户余额查询全量展示总余额/充值/赠金字段，支持手动刷新

### @ 文件引用
- 输入框 `@` 触发文件选择器，快速引用工作区文件/文件夹
- 引用内容仅在当前轮注入上下文，未持续引用自动降级
- 支持 @文件夹批量引用，可配置文件类型过滤规则

### 多模态图片输入
- 三路径图片输入：剪贴板粘贴、文件拖拽、`@` 引用图片文件（PNG/JPG/JPEG/WebP）均可插入图片，缩略图内联预览，支持单张删除与批量清空
- 格式与容量约束：单张 ≤10MB、单条消息至多 10 张，超限明确提示并拒绝插入
- 模型多模态能力标识：预置目录按官方能力标记（Kimi K3、DeepSeek V4 Flash Vision Exp、GLM-4V、Qwen-VL、豆包 Vision、GPT-4o、Claude 3+ 等原生视觉模型），动态拉取按 capabilities/modalities/supports_vision/vision 四路探测 + 已知视觉模型 ID 模式兜底，命中视觉模型默认勾选；未自动识别的模型可在设置页「模型元数据校准」手动勾选（校准值重新拉取时保留）；不支持图片的模型发送前拦截提示（不消耗 Token），拦截时输入内容全部保留
- 图片以 Base64 Data URL 按 OpenAI 兼容协议下发（无需图床，兼容 Kimi 等「图片必须 base64、不接受公网图片 URL」的服务商约束）
- 图片随会话持久化：历史回显、会话续接、重新生成均原样复用；上下文压缩时以标注降级，不丢关键信息
- 操作指引：插入图片（粘贴/拖拽/`@`）→ 底部模型下拉框切换多模态模型 → Enter 发送；模型不支持图片时给出明确提示，切换模型后可直接重发，无需重新插入图片

### 会话管理
- 新建对话、历史列表（时间倒序）、关键词搜索、重命名、删除、导出 JSON
- 本地持久化：默认存储于工作区 `.code-agent/history`，支持自定义绝对路径
- 历史目录实时监听：会话文件增删改自动同步列表；启动强制全量扫描，损坏文件跳过并记录日志
- 会话续接：打开历史会话自动恢复完整上下文，超阈值自动轻量压缩

### 运行模式与权限边界（双层权限体系）

插件采用「运行模式 - 权限管理」两级权限体系，两层从属关系与作用边界如下：

**第一层 · 运行模式**（对话模式 / 智能体模式）：决定插件的整体能力边界，控制可用工具集的范围，是所有权限规则的前置判断条件。

- **智能体模式**：完整 Agent 能力——读取全域开放（工作区内/外，无需确认）；写入仅限工作区范围内（增删改文件），工作区外文件强制只读；保留完整终端命令执行能力；支持多轮任务自主闭环。
- **对话模式（只读文件问答）**：完整开放只读类文件操作——读取工作区内所有文件，同时支持工作区外的本地文件与目录（文件内容读取、目录结构遍历、代码检索、diff 对比，含 @ 引用与右键注入）；仅挂载只读工具，文件写入/编辑/删除/重命名/新建目录与终端命令执行全局禁用，越权操作在调度层与执行校验层双重拦截并提示「对话模式仅支持只读文件问答，如需修改文件或执行命令，请切换至智能体模式」。

**第二层 · 权限管理**（询问模式 / 全自动模式）：属于智能体模式下的子配置，仅控制智能体模式中工作区内文件写入操作的确认机制，对话模式下不生效、无作用。

- **询问模式**：智能体模式下生效，所有工作区内的文件增删改操作执行前弹出确认面板（展示操作详情与 diff 预览），用户同意后方可执行；文件读取操作无需确认。
- **全自动模式**：智能体模式下生效，工作区内的文件增删改操作自主执行，无需逐次确认；仍严格限制在工作区范围内，禁止越权修改工作区外文件。

模式切换即时生效，无缓存残留；底部快捷栏权限下拉框随运行模式联动——对话模式下置为禁用态并显示「🔒 对话模式·只读权限」，切换回智能体模式自动恢复可点击。

### 安全权限体系
- 文件读取权限完整开放：任何运行模式下均可读取工作区内所有文件及工作区外的本地文件与目录（读操作无副作用，无需确认）
- 文件写入分级权限：智能体模式下工作区内可写（询问/全自动模式控制确认机制，全自动直接放行）；工作区外文件任何运行模式下只读不可修改，写入执行前拦截；对话模式下写入全局禁用
- 终端命令默认确认，可开启工作区内免确认；内置高危命令拦截规则（破坏性命令强制二次确认）；终端命令执行不受询问/全自动模式影响，对话模式下终端全局禁用
- 双层拦截保障：调度层（工具集按运行模式挂载）+ 执行层（统一权限校验模块，所有工具调用必经）双重拦截，底层杜绝模式越权
- 操作审计：所有文件修改、终端执行、越权拦截均写入本地操作日志，支持回溯排查
- API Key 按服务商独立存储于 VSCode 原生 SecretStorage 系统密钥库，与配置文件、工作区数据完全隔离；所有持久化文件（配置、历史会话、审计日志）均不写入任何形式密钥，数据全部本地化

## 使用指引

1. 安装插件后，点击左侧活动栏 Code Agent 图标打开侧边栏对话
2. 点击面板右上角 ⚙ 进入设置，配置模型服务商：
   - 「模型配置」栏按「服务商管理区 + 运行配置/编辑配置两级分区」展示——点击「新增模型服务商」，名称与 Base URL 输入框支持 ▾ 下拉快捷选择预置厂商（DeepSeek、智谱 AI、月之暗面 Kimi、通义千问、豆包、OpenAI、Anthropic），也可手动输入任意自定义地址；模型拉取失败时可勾选「仍要创建」强制创建后手动添加模型
   - 预置 DeepSeek 服务商（Base URL：`https://api.deepseek.com`，OpenAI 兼容协议），填写对应 API Key 即可使用
   - 无密钥新增时使用预置兜底模型列表，配置密钥后自动调 `/models` 拉取最新模型列表覆盖兜底（可随时手动刷新），密钥保存后即时生效无需重启
   - 「运行配置 · 全局默认」分组的「默认服务商（全局默认）」：运行时生效，决定新建会话默认使用的服务商与主界面默认加载的模型列表，切换后主界面模型下拉框与默认模型同步联动
   - 「编辑配置 · 参数编辑区」分组的「编辑目标服务商」：仅切换查看/修改模型元数据的目标服务商，不影响当前默认使用的服务商；修改默认服务商后编辑区自动同步跟随
   - 可校准模型元数据、调整推理参数（`max_tokens` 默认 100000、最大工具调用轮次默认 128）、安全权限等
   - API Key 仅存于 VSCode 系统密钥库（SecretStorage），不写入任何项目文件与持久化数据
3. 在输入框输入需求，Enter 发送（Shift+Enter 换行）
4. 底部操作栏可随时切换模型与运行模式：
   - **智能体模式**：完整 Agent 能力，可读写工作区文件、执行终端命令
   - **对话模式**：只读文件问答，可读取工作区及本地文件回答问题，不能修改文件或执行命令（此时权限下拉框自动置为「🔒 对话模式·只读权限」禁用态）
   - **权限下拉框（询问/全自动，仅智能体模式下生效）**：控制工作区内文件修改的确认方式，对话模式下不生效
5. 输入 `@` 引用工作区文件/文件夹
6. 编辑器中选中代码 → 右键「Add to Code Agent」，以行范围引用注入当前对话输入框
7. 使用「Code Agent: 打开对话面板」命令可在独立编辑器面板中使用

## 手动打包教程

想自己从源码构建 `.vsix` 安装包？按以下步骤操作：

### 前置条件

- [Node.js](https://nodejs.org/) 18 及以上版本
- npm（随 Node.js 一起安装）
- Windows 用户建议在 PowerShell 或 CMD 中操作（PowerShell 5.x 请用 `npm.cmd` 代替 `npm`）

### 打包步骤

```bash
# 1. 进入项目根目录（包含 package.json 的目录）
cd code-agent

# 2. 安装依赖（首次打包或依赖变更后执行）
npm install

# 3. 类型检查（可选但推荐，确保代码无类型错误）
npm run typecheck

# 4. 打包（自动执行 构建 → 准备输出目录 → 生成 vsix）
npm run package
```

### 产物位置

打包完成后，安装包自动输出到项目的 `releases/` 目录：

```
releases/
└─ code-agent-1.4.5.vsix   ← 文件名中的版本号来自 package.json 的 version 字段
```

### 发布新版本

1. 修改 `package.json` 中的 `"version"` 字段（如 `1.0.0` → `1.1.0`）
2. 在 `CHANGELOG.md` 顶部按日期添加新版本条目
3. 重新执行 `npm run package`，自动生成 `releases/code-agent-1.1.0.vsix`

### 安装到 VSCode

1. 打开 VSCode → 左侧扩展面板（Ctrl+Shift+X）
2. 点击右上角「···」菜单 → 选择「从 VSIX 安装…」
3. 选择 `releases/` 下的 `.vsix` 文件，安装后重启窗口即可生效

### 常见问题

- **PowerShell 报错**：`npm` 无法识别时改用 `npm.cmd`（如 `npm.cmd run package`）
- **同版本重复打包**：会覆盖 `releases/` 中的同名文件，无提示
- **打包内容**：`.vscodeignore` 已自动排除源码、会话历史（`.code-agent/`）、旧安装包等，包内仅含运行所需文件
- **卸载重装**：覆盖安装（同版本升级）不会丢失配置与 API Key（存于 VSCode 全局设置与系统密钥库，不在插件目录内）；如需彻底清除请卸载后手动删除 `settings.json` 中的 `codeAgent.*` 配置与各工作区的 `.code-agent` 目录

## 项目结构

```
src/            扩展主进程源码
├── config/      配置管理模块（读写/校验/持久化）
├── models/      模型适配层（适配器设计模式，OpenAI 协议）
├── agent/       Agent 调度引擎（任务规划/工具调度/多轮闭环）
├── context/     上下文管理（Token 统计/分层/摘要压缩）
├── tools/       工具执行模块（文件/终端操作与安全校验）
├── security/    安全权限体系 + 操作审计
├── sessions/    会话持久化 + 用量统计
├── services/    核心服务编排（消息路由/权限桥接）
├── webview/     WebView 宿主（postMessage 双向通信）
└── extension.ts 扩展入口

webview-ui/      React 前端（对话面板/会话列表/设置面板）
scripts/         构建辅助脚本（图标生成、打包前置处理）
docs/            迭代需求规格说明书与开发文档
releases/        打包产物（各版本 .vsix 安装包）
```

技术栈：TypeScript + VSCode Extension API + WebView + React，esbuild 构建。
