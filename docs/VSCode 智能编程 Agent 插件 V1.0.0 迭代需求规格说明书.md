# VSCode 智能编程Agent插件 V1.0.0 迭代需求规格说明书

**基准版本**：V0.9.0 **迭代版本**：1.0.0 **需求类型**：权限体系架构重构 + UI交互逻辑对齐 + 全量回归校验 **核心目标**：彻底厘清「运行模式」与「权限管理」两层体系的层级关系与作用边界，修正各场景下的文件操作权限规则；同步优化快捷栏、设置页的UI控件逻辑与配置项结构，消除概念混淆与交互矛盾；完成全链路功能回归校验，保障现有成熟功能无负向优化，整体交付稳定正式版本。

------

## 一、双层权限体系架构重构（P0 最高优先级）

### 问题背景

当前运行模式与权限管理概念边界模糊，两类模式的从属关系不明确，对话模式与智能体模式的权限划分存在缺失与越权风险；同时设置页存在重复、矛盾的权限配置项，用户无法准确理解各模式的能力范围，权限规则与UI状态也存在不匹配问题。

### 需求描述

重新定义「运行模式-权限管理」的两级体系架构，明确层级从属关系与各场景权限边界，在工具调度层与执行校验层实现统一管控：

1. 体系层级定义
   - 第一层：**运行模式**（对话模式 / 智能体模式）：决定插件的整体能力边界，控制可用工具集的范围，是所有权限规则的前置判断条件。
   - 第二层：**权限管理**（询问模式 / 全自动模式）：属于智能体模式下的子配置，仅控制智能体模式中文件写入操作的确认机制，对话模式下不生效、无作用。
2. 对话模式权限规则
   - 读取权限：全域开放，支持读取工作区目录内所有文件，同时支持读取工作区外本地任意路径的文件与目录结构，满足基于文件内容的问答需求。
   - 写入权限：全局禁用，无论工作区内或工作区外，均不允许任何文件增删改、重命名、新建目录等变更操作。
   - 终端权限：全局禁用所有终端命令执行能力，不发起任何系统命令调用。
   - 工具集约束：仅挂载文件读取、目录遍历类只读工具，从Agent调度层屏蔽所有写入类、执行类工具。
3. 智能体模式权限规则
   - 读取权限：全域开放，与对话模式一致，支持读取工作区内外所有文件与目录，读取操作无需用户确认。
   - 写入权限：仅开放工作区范围内的文件增删改权限，工作区外文件强制只读，禁止任何写入操作，该限制不受权限管理模式影响。
   - 写入执行规则：工作区内的写入操作，受「权限管理」的询问/全自动模式约束；读取操作不受权限管理模式影响，直接执行。
   - 终端权限：保留完整终端命令执行能力，原有规则保持不变。
4. 权限管理模式作用规则
   - **询问模式**：智能体模式下生效，所有工作区内的文件增删改操作，执行前必须弹出确认面板，展示操作详情与diff预览，用户同意后方可执行；文件读取操作无需确认。
   - **全自动模式**：智能体模式下生效，工作区内的所有文件增删改操作可自主执行，无需用户逐次确认；但仍严格限制在工作区范围内，禁止越权修改工作区外文件。

### 验收标准

- 对话模式下可正常读取工作区内外所有文件并作答，所有写入、终端操作均被拦截，无越权执行；
- 智能体模式下可正常读写工作区文件，工作区外文件仅支持读取，无法执行任何写入操作；
- 询问模式下写入操作正常弹出确认面板，读取操作无弹窗打断；全自动模式下工作区写入自动执行，不越权操作外部文件；
- 权限管理模式仅在智能体模式下生效，对话模式下不产生任何权限影响。

## 二、UI控件与配置页逻辑对齐优化（P0 最高优先级）

### 问题背景

当前底部快捷栏、全局设置页存在权限相关控件逻辑不匹配、配置项冗余矛盾的问题，与新的双层权限体系不匹配，易造成用户概念混淆，需同步完成UI层的适配重构。

### 需求描述

1. 底部快捷栏控件联动适配
   - 运行模式下拉框（对话模式/智能体模式）保持原有位置与交互逻辑不变。
   - 权限管理下拉框新增状态联动规则：当切换至对话模式时，下拉框置为禁用态（灰色不可点击），占位文本统一显示为「对话模式·只读权限」；切换至智能体模式时，自动恢复可点击状态，展示当前选中的询问/全自动模式。
   - 两类下拉框视觉层级区分明确，文案标注清晰，避免用户混淆。
2. 设置页权限配置项重构
   - 梳理原有安全权限分组下的冗余配置项，合并重复的权限控制选项，消除逻辑矛盾，统一概念命名。
   - 配置项重新排布：
     1. 运行模式默认配置：设置插件启动时的默认运行模式，作用于全局。
     2. 智能体专属权限配置：明确标注「仅智能体模式下生效」，包含权限管理模式（询问/全自动模式）。
   - 每个配置项补充清晰的 tooltip 说明，明确作用范围与生效条件，避免用户理解歧义。

### 验收标准

- 底部快捷栏权限下拉框随运行模式正确切换禁用/启用状态，文案准确，无逻辑冲突；
- 设置页权限配置项层级清晰，无重复、矛盾选项，说明文案准确易懂；
- UI状态与底层权限规则完全一致，无展示与实际能力不匹配的问题。

## 三、全量功能回归校验（P0 必做）

### 问题背景

权限体系属于插件底层核心链路，重构涉及工具调度、执行校验、UI多模块，修改范围广，存在波及其他成熟功能的风险，需执行全量回归验证，避免引入功能回归。

### 需求描述

完成权限体系重构后，对所有已稳定的核心功能执行全量回归校验，覆盖范围包括但不限于：

- 智能体模式完整执行链路（文件读写、终端执行、多轮工具调用）
- 对话模式文件问答能力
- 上下文管理与 Token 实时统计
- 历史会话读写、续接与删除
- 编辑器文件修改高亮联动
- 多模型切换与配置管理
- 对话滚动交互与区块折叠
- 思考链分段展示与分层渲染

校验标准：所有功能表现与 V0.9.0 稳定版本完全一致，无功能失效、交互异常、样式错乱、数据统计错误等问题；校验中发现的关联缺陷需同步修复闭环。

### 验收标准

- 核心功能零回归，所有已验证特性保持原有体验；
- 权限修改仅作用于模式能力边界，不波及其他模块逻辑。
