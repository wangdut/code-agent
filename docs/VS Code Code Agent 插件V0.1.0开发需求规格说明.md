# VSCode 智能编程Agent插件 产品需求规格说明书
**版本**：V1.0  
**适用范围**：指导插件全量代码开发与功能实现  
**设计原则**：Token效率优先、安全可控、交互高效、架构可扩展

## 一、产品概述
### 1.1 产品定位
本产品是一款VSCode原生扩展插件，基于大语言模型API实现端到端智能编程Agent能力，支持代码生成、文件编辑、终端执行、多轮任务自主闭环。产品对标 **Qoder、Cline (Claude Dev)、CodeX** 等行业主流AI编程插件，在交互范式、功能架构、视觉体验上对齐业界优秀实践，核心差异化优势为极致的Token效率优化、灵活的多模型切换机制与分级安全权限体系。

### 1.2 参考标杆
- 交互与视觉：对齐 Qoder、CodeX 插件的面板布局、按钮体系、执行态呈现样式
- Agent架构：参考 Cline 开源插件的工具调度、任务执行链路与多轮闭环设计
- 上下文管理：借鉴主流开源方案的分层上下文、结构化摘要压缩机制

## 二、核心功能需求
### 2.1 多模型接入与配置体系（P0）
#### 2.1.1 多模型兼容层
- 采用**适配器设计模式**封装模型调用层，统一接口标准，兼容OpenAI协议的所有模型服务，支持快速扩展新模型
- 首批深度适配DeepSeek全系列模型，包括 `deepseek-v4-flash`、`deepseek-v4-pro` 等版本，支持用户自定义新增同协议模型
- 每个模型绑定独立元数据：模型标识、总上下文窗口大小、最大输出Token数、计费类型

#### 2.1.2 全局设置面板
- 双入口：侧边栏功能按钮入口 + VSCode原生扩展设置页入口
- 配置项按模块分级，覆盖完整参数：
  1. **模型配置**：API Key、接口Base URL、模型列表增删改、默认模型、请求超时、网络代理
  2. **推理参数**：全局默认 temperature、top_p、max_tokens、frequency_penalty 等生成参数
  3. **Agent行为**：默认执行模式、终端命令确认开关、自动上下文压缩阈值
  4. **存储配置**：历史对话存储路径（默认工作区目录，支持自定义绝对路径）
  5. **安全权限**：文件操作权限分级、高危命令拦截开关
  6. **高级设置**：日志级别、调试模式、更新检测

#### 2.1.3 快捷切换控件
- 固定位置：对话输入框底部常驻操作栏
- **模型切换下拉框**：展示所有已配置模型，一键切换当前对话生效模型，切换即时生效且不丢失当前上下文
- **模式切换下拉框**：包含两种运行模式
  - 对话模式：纯问答交互，Agent不调用任何工具、不执行文件与终端操作
  - 智能体模式：激活完整Agent能力，可自主调度工具、编辑文件、执行终端命令完成任务

### 2.2 智能编程Agent引擎（P0）
#### 2.2.1 核心能力
- 任务规划：基于用户需求自主拆解执行步骤，调度对应工具迭代推进任务
- 标配工具集：文件读取、文件写入/编辑、目录遍历、代码检索、终端命令执行、diff对比
- 多轮闭环：工具执行结果自动回传给模型，支持多轮自我修正直至任务完成

#### 2.2.2 执行态交互规范
- 步骤可视化：按顺序展示规划、工具调用、执行结果全链路，对齐Qoder/Cline的步骤进度样式
- 文件修改预览：所有编辑操作展示 inline diff 视图，高亮标记新增/删除/修改行
- 终端输出：采用等宽字体的终端风格展示命令执行结果，支持实时流式输出
- 权限申请：需用户确认的操作弹出确认面板，展示操作详情与影响范围，提供同意/拒绝选项
- 状态标识：执行中、成功、失败、等待确认等状态均有明确的视觉反馈

### 2.3 上下文管理与Token优化（P0 核心特性）
#### 2.3.1 分层上下文架构
采用四层优先级管理机制，按权重分配Token配额：
1. **系统指令层**：Agent角色定义、工具说明、安全规则，固定占用，优先级最高
2. **活跃对话层**：最近N轮完整对话与执行结果，保留全量信息
3. **历史摘要层**：早期对话经结构化摘要压缩后保留，仅存储核心指令与关键结论
4. **引用资源层**：用户@引用的文件/代码片段，按需加载，未持续引用则自动降级

#### 2.3.2 上下文压缩机制
- **自动压缩**：当上下文总Token数达到模型总窗口的75%时，自动触发压缩，将最早的活跃对话转为摘要层，将Token占用控制在阈值内
- **手动压缩**：对话面板顶部提供独立按钮，用户可主动触发压缩
- **差异化压缩算法**：采用结构化摘要方案，针对不同内容类型执行不同策略：
  - 代码片段：保留函数签名与核心逻辑，压缩冗余注释与非核心代码
  - 执行日志：仅保留执行结论与关键报错，裁剪冗余输出
  - 对话文本：提炼核心需求与结论，去除冗余表述与重复沟通
- 压缩可回溯：生成压缩记录，支持用户查看压缩前的完整历史

#### 2.3.3 Token用量可视化
- **会话级实时统计**：对话面板顶部展示「已用Token / 总上下文窗口」进度条，同时标注最大输出Token限制
- **今日用量统计**：对接模型官方用量查询API，展示当日累计输入Token、输出Token、总消耗，按自然日自动重置

#### 2.3.4 @文件引用机制
- 输入框支持 `@` 符号触发文件选择器，快速引用工作区内的文件/文件夹
- 被引用文件仅在当前轮对话注入上下文，未被后续对话持续引用时自动降级，避免无效Token占用
- 支持@文件夹批量引用，可配置文件类型过滤规则

### 2.4 会话管理（P0）
#### 2.4.1 会话操作
- 新建对话：侧边栏顶部提供新建按钮，创建空白会话
- 历史列表：侧边栏展示历史会话，按时间倒序排列，支持关键词搜索
- 会话管理：支持重命名、删除、导出为JSON文件

#### 2.4.2 本地持久化
- 默认存储路径：当前工作区根目录下的 `.code-agent/history` 文件夹
- 自定义路径：支持在设置中配置全局存储路径
- 存储内容：完整对话记录、上下文状态、模型配置、执行日志，采用JSON格式存储

#### 2.4.3 会话续接
- 打开历史会话时自动恢复对话界面与完整上下文
- 续接时自动检测Token占用，若超过阈值自动执行一次轻量化压缩，保障续接后交互效率

### 2.5 安全权限体系（P0）
#### 2.5.1 文件操作分级权限
- **工作区范围内文件**
  - 全自动模式：Agent无需用户确认，可直接读取、编辑、写入工作区内文件
  - 询问模式：每次文件修改操作前，必须展示diff预览，用户确认后方可执行
- **工作区范围外文件**
  - 强制只读：仅允许读取内容，禁止任何写入、修改、删除操作
  - 读取提示：读取前弹出安全提示，用户确认后方可加载内容

#### 2.5.2 终端操作权限
- Agent可执行终端命令（如依赖安装、脚本运行等），命令继承当前系统用户权限
- 默认执行前需用户确认，支持设置中开启「工作区内命令免确认」
- 内置高危命令拦截规则，破坏性命令强制二次确认

#### 2.5.3 操作审计
所有文件修改、终端执行操作均写入本地操作日志，包含操作时间、内容、结果，支持回溯排查。

## 三、UI/UX 设计规范（P1）
### 3.1 整体布局
- 活动栏入口：默认注册于VSCode左侧活动栏，遵循VSCode扩展规范，支持用户自由拖动至右侧侧边栏
- 面板结构：采用「侧边栏会话列表 + 主区域对话面板」布局，对齐Cline/Qoder交互范式
- 面板分区：顶部功能按钮区、对话内容滚动区、底部输入与快捷操作区

### 3.2 视觉风格
- 遵循VSCode原生设计语言，复用系统主题色变量，完美适配深色/浅色主题
- 视觉质感、按钮样式、消息气泡、执行组件对齐Qoder、CodeX的专业简约风格
- 信息层级清晰：用户消息、AI回复、系统消息、工具结果采用差异化视觉样式
- 图标统一使用VSCode内置Codicon图标库，保持原生一致性

### 3.3 交互规范
- 输入框：支持多行输入、Enter发送、Shift+Enter换行，@触发文件联想
- 快捷操作：每条AI消息附带复制代码、应用修改、重新生成等快捷按钮
- 加载反馈：所有异步操作均有加载动画与进度提示，避免无响应状态

## 四、技术实现要求（P0）
### 4.1 技术栈
- 开发语言：TypeScript
- 扩展基础：基于 VSCode Extension API 原生开发
- UI层：WebView + React 实现对话面板
- 通信机制：Extension Host 与 WebView 通过 `postMessage` 双向通信

### 4.2 模块化架构
采用低耦合高内聚的分层架构，各模块职责单一：
1. 配置管理模块：配置读写、校验、持久化
2. 模型适配层：统一调用接口，各模型适配器独立实现
3. Agent调度引擎：任务规划、工具调度、多轮对话管理
4. 上下文管理模块：Token统计、分层管理、摘要压缩、文件引用
5. 工具执行模块：封装文件、终端操作与安全校验逻辑
6. 存储模块：会话持久化、日志管理
7. UI渲染模块：WebView界面渲染与事件处理

### 4.3 开源参考要求
Agent调度、上下文压缩、工具封装等核心逻辑优先参考业界成熟开源实现，规避设计缺陷，避免重复造轮子。

## 五、打包与发布（P0）
1. **产物输出**：使用官方 `vsce` 工具打包为 `.vsix` 格式安装包，支持本地侧载安装
2. **元信息配置**
   - `package.json` 中作者字段为 `wangh`
   - 版本号采用语义化版本规范（SemVer），初始版本为 `0.1.0`
   - 插件名称、描述、分类、图标、最低VSCode版本等信息完整
3. **文档要求**：插件README介绍页、市场详情页包含作者署名、功能说明与使用指引

## 六、非功能性需求
1. **性能**：常规对话首字节响应延迟<200ms；万级Token上下文压缩耗时<1s；插件冷启动时间<500ms
2. **兼容性**：支持VSCode 1.80.0及以上版本，兼容Windows/macOS/Linux全平台
3. **可扩展性**：模型、工具、压缩算法均采用注册制，支持无侵入扩展
4. **数据安全**：所有本地数据（对话、配置、密钥）均存储于用户本地，API密钥加密存储，无额外数据中转
