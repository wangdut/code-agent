# VSCode 智能编程Agent插件 V0.8.0 迭代需求规格说明书

**基准版本**：V0.7.0 

**迭代版本**：0.8.0 

**需求类型**：对话布局体系重构 + 推理链路分层展示优化 

**核心目标**：构建「全局滚动+区块内二级滚动」的双层滚动体系，为所有内容子块增加折叠收纳能力，提升长任务下的全局把控性；补全推理节点（思维链）与深度思考过程的分层展示逻辑，落地思考链与执行节点一一对应的分段挂载方案，修复 V0.7.0 中思考链展示不完整的问题。现有其余功能与视觉风格保持不变。

------

## 一、对话区双层滚动与区块折叠体系重构（P0 最高优先级）

### 问题背景

当前对话流仅支持单一级别的全局滚动，思考过程、工具执行结果、终端输出等长内容区块会无限制撑高对话区域，导致单块内容占据大量视口空间，用户难以宏观浏览完整执行链路；同时缺少区块级折叠收纳能力，长任务下梳理全链路效率低。

### 需求描述

重构对话流内容区块的布局体系，落地二级滚动与统一折叠机制，兼顾长内容详情查看与全链路宏观浏览：

1. 两级滚动条体系
   - 一级滚动：对话面板全局滚动条，控制完整对话流的上下浏览，兼容现有智能滚动与自动归位逻辑。
   - 二级滚动：所有独立内容子块（思考过程区块、工具执行结果区块、代码Diff区块、终端输出区块等）均设置统一的最大高度阈值，内容超出阈值后，区块内部出现独立滚动条，内容仅在区块可视区域内滚动，不再无限制撑高对话面板。
   - 所有子块滚动条样式对齐 VSCode 原生滚动条风格，保持视觉一致性。
2. 区块统一折叠/展开能力
   - 每个独立内容子块的头部栏均新增折叠/展开切换按钮，支持将区块收起为单行标题条目，仅展示区块类型与核心状态摘要（如思考块显示「思考过程」、工具块显示「read_file · 执行成功」）。
   - 所有区块默认展开，用户可手动切换折叠状态；折叠状态不影响流式输出的内容更新，展开后可查看完整内容。
   - 折叠后条目高度统一，形成清晰的执行链路条目列表，便于用户宏观把控完整任务流程。
3. 交互兼容规范
   - 所有子块的最大高度、内边距、头部栏样式、滚动交互保持统一规范，与插件整体视觉风格兼容。
   - 用户手动滚动区块内部时，不触发全局滚动的自动归位逻辑，避免操作冲突。

### 验收标准

- 对话面板存在全局滚动条，所有长内容子块存在内部独立滚动条，实现两级滚动控制；
- 所有内容子块均支持折叠/展开，折叠后仅保留单行标题条目，样式统一；
- 长内容子块不会无限制撑高对话面板，视口内可同时展示多个区块条目；
- 与现有智能滚动、自动归位逻辑兼容，无交互冲突。

## 二、推理链路分层展示与思考链分段挂载修复（P0 最高优先级）

### 问题背景

V0.7.0 版本未明确区分「推理节点（思维链/执行轨迹）」与「深度思考过程」两个层级，导致完整思维链展示缺失，且思考链分段挂载未完全落地，仍存在内容集中堆积、与执行动作脱节的问题，用户无法对应每一步操作的决策逻辑与推导过程。

### 需求描述

重构思考链路的输出与渲染逻辑，明确两层内容的定位与时序，彻底落地分段分散式展示，实现推理与动作一一对应：

1. 内容分层定义

   - **推理节点（思维链/执行轨迹）**：属于执行链路的主干内容，是 Agent 每一步的决策结论、动作说明与结果小结，例如任务拆解说明、下一步操作意图、执行结果总结等。内容精简，紧跟对应执行节点的前后位置，串联完整执行链路。
   - **深度思考过程**：属于执行链路的详情内容，是 Agent 推导决策的完整推理过程，用于解释决策依据。深度思考过程挂载在对应推理节点的下方，作为可折叠、可内部滚动的独立子块存在。

2. 思考链分段挂载落地

   严格遵循「推理节点 → 深度思考过程 → 工具调用执行 → 执行结果小结」的时序结构，将完整思维链拆分为与每一步操作一一对应的片段，分散嵌入到执行链路的对应位置，彻底替代集中式尾部输出。

   - 工具调用前：输出对应推理节点，说明当前步骤的执行意图；搭配对应深度思考块，展示推导过程。
   - 工具执行后：输出对应推理节点，说明执行结果与下一步方向；复杂结果搭配对应深度思考块，展示结果分析过程。
   - 全链路所有工具执行步骤完成后，保留独立的最终总结回复，作为任务闭环收尾。

3. 排版与样式规范

   - 推理节点采用轻量的主干样式，与正式回复视觉层级区分，保障链路可读性；内容按语义自然分段，无堆叠拥挤问题。
   - 深度思考过程保持现有视觉风格，作为二级子块存在，支持内部滚动与折叠收纳。

### 验收标准

- 执行链路中存在清晰的「推理节点+深度思考」分层结构，完整思维链内容正常展示，无缺失；
- 所有思考内容均分散对应到每一步执行动作的前后，不再集中堆积在对话末尾；
- 推理节点与思考过程层级区分明确，对应关系清晰，可对照理解每一步的决策逻辑；
- 任务结束后的最终总结回复保留，收尾体验与原有版本一致。
