# VSCode 智能编程Agent插件 V1.4.0 迭代需求规格说明书

**基准版本**：V1.3.5 **迭代版本**：1.4.0 **需求类型**：多模态输入能力扩展 + 模型能力适配 + 质量保障 **核心目标**：补全对话输入框的多模态（图片）输入能力，适配支持视觉理解的大模型服务；建立模型能力校验机制，对不支持对应模态的模型给出明确友好提示；所有修改严格限定于输入层与模型适配层，确保存量文本对话、Agent 执行等成熟功能零负向优化。

------

## 一、多模态输入能力体系建设（P0 最高优先级）

### 1.1 输入框多模态交互能力

**问题背景**：当前对话输入框仅支持纯文本输入与 @ 文件引用，不支持图片等多模态内容的直接输入，无法利用具备视觉理解能力的模型特性，能力边界存在短板。

**需求描述**：

1. 多路径图片输入支持

   ：输入框开放三种图片输入入口，全场景覆盖用户使用习惯：

   - 剪贴板粘贴：复制图片后在输入框内直接粘贴，自动识别并插入图片内容；
   - 文件拖拽：将本地图片文件拖拽至输入框区域，自动校验格式并插入；
   - @ 文件引用：通过 `@` 符号选择本地图片文件，统一纳入多模态输入链路。

2. **输入内预览与管理**：插入的图片在输入框内以缩略图形式内联展示，每张图片附带独立删除按钮；支持批量清空多模态内容，操作不影响已输入的文本内容。

3. **格式与大小约束**：默认支持 PNG、JPG/JPEG、WebP 主流图片格式，非支持格式插入时给出明确格式提示；设置单张图片大小上限（默认 10MB），超出时提示用户压缩后再上传，避免请求体过大引发接口异常。

### 1.2 多模态请求协议适配

**问题背景**：现有消息请求结构仅支持纯文本内容，无法承载多模态数据，需适配 OpenAI 兼容协议的标准多模态消息格式，保障对不同厂商模型的通用兼容性。

**需求描述**：

1. 重构消息内容结构，严格遵循 OpenAI 兼容协议的多内容块规范，即消息 `content` 字段为数组格式，按顺序包含 `text`（文本）、`image_url`（图片）两类内容块，实现文本与图片的组合请求。
2. 本地图片统一采用 Base64 编码方式嵌入请求体，兼容绝大多数遵循 OpenAI 协议的模型服务，无需额外依赖图床服务。
3. 多模态消息组装逻辑下沉至模型适配器统一层，所有服务商复用同一套协议逻辑，保持现有适配器架构的通用性与可扩展性。

### 1.3 模型能力校验与降级提示

**问题背景**：并非所有模型均支持多模态输入（如 DeepSeek 系列暂不支持图片理解），无前置校验直接发送会导致接口报错，用户无法明确失败原因，体验不友好。

**需求描述**：

1. 在模型元数据中新增「多模态支持」标识字段：预置模型按官方能力准确标记；动态拉取的模型若接口返回能力信息则自动同步，未返回则默认标记为不支持，同时开放手动修改入口，允许用户在模型配置中调整该标识。
2. 新增请求前置校验机制：当输入内容包含图片等多模态数据时，发送前先校验当前选中模型是否支持对应模态；不支持时弹出明确提示：「当前模型 [模型名称] 不支持图片输入，请更换支持多模态的模型后重试」，同时拦截本次请求，不产生 Token 消耗。
3. 纯文本输入不受该校验规则影响，所有模型均可正常发起对话，完全不改变原有使用体验。

### 验收标准

- 输入框支持粘贴、拖拽、@ 引用三种方式插入图片，缩略图展示正常，可单独删除，不干扰文本输入；
- 支持多模态的模型可正常识别图片内容并作答，请求格式符合协议规范；
- 不支持多模态的模型发送图片时，弹出明确提示，请求被拦截，无接口报错与无效消耗；
- 纯文本对话、@ 普通代码文件等原有输入功能完全正常，无交互与功能回归。

## 二、代码审查与全量功能回归校验（P0 必做）

### 问题背景

输入层与消息协议属于核心基础链路，修改涉及消息组装、请求发送、输入交互多个模块，存在引入隐性缺陷的风险，需通过代码审查与全量回归保障存量功能稳定，严格杜绝负向优化。

### 需求描述

1. **专项代码审查**：重点覆盖多模态消息组装逻辑、模型能力校验链路、输入框交互逻辑，确保无状态异常、无内存泄漏、无协议格式错误、无安全风险，代码风格与现有工程保持一致。

2. 全量功能回归

   ：覆盖所有存量核心功能，范围包括但不限于：

   - 文本对话、智能体模式完整执行链路
   - @ 文件引用、编辑器右键代码注入
   - 多服务商切换、模型切换、参数配置
   - 上下文 Token 统计、自动/手动压缩
   - 历史会话读写、续接、删除管理
   - 双层权限体系、安全模式切换
   - 编辑器文件修改高亮联动

3. **专项场景测试**：覆盖多模态输入全场景、模型能力校验场景、格式/大小异常场景、纯文本兼容场景，确保边界 case 处理完善，无异常崩溃。

### 验收标准

- 代码审查无逻辑漏洞、安全风险与规范问题；
- 存量核心功能零回归，体验与 V1.3.5 版本完全一致；
- 多模态相关场景处理正确，边界 case 无异常报错与状态错乱。
