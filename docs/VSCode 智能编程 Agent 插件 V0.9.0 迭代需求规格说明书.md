# VSCode 智能编程Agent插件 V0.9.0 迭代需求规格说明书

**基准版本**：V0.8.0 

**迭代版本**：0.9.0 

**需求类型**：运行模式权限模型修正 + 全链路回归校验 **核心目标**：修正对话模式的文件访问权限边界，补全只读文件问答能力，明确两种运行模式的权限分工；同步完成核心功能全量回归校验，确保修改不引入功能回归，其余现有功能与交互体验保持不变。

------

## 一、对话模式权限体系修正（P0 最高优先级）

### 问题背景

当前「对话模式」仅支持纯文本问答交互，未开放文件读取权限，无法响应用户基于工作区项目文件、本地文件的问答需求，模式能力边界设置不合理，未覆盖“基于文件的只读问答”这一高频场景。

### 需求描述

重新定义两种运行模式的权限边界，在工具调度层与执行层实现双维度权限管控，确保能力边界清晰、权限隔离严格：

1. 对话模式权限规则（重构）
   - 读取权限：完整开放只读类文件操作能力，支持读取工作区目录内所有文件，同时支持读取工作区外的本地文件与目录；支持文件内容读取、目录结构遍历、代码片段引用等只读操作，满足基于文件内容的问答需求。
   - 写入权限：全局禁用所有文件变更操作，包括文件写入、编辑、删除、重命名、新建文件/目录等，任何写入类操作均在执行前拦截。
   - 终端权限：禁用所有终端命令执行能力，不允许发起任何系统命令调用（如果需要，阅读文件的相关命令除外）。
   - 工具集限制：对话模式下仅挂载文件读取、目录浏览等只读工具，从 Agent 调度层面屏蔽文件编辑、终端执行等写入类工具，避免无效工具调用。
   - 拦截提示：当触发越权操作时，向用户返回明确提示：「对话模式仅支持只读文件问答，如需修改文件或执行命令，请切换至智能体模式」。
2. **智能体模式权限规则（保持不变）** 完整保留原有能力与权限体系，包括工作区文件读写权限、终端命令执行能力、询问/全自动双安全模式、工作区外文件只读限制等，确保现有功能无任何衰减。
3. **统一权限校验层** 在工具执行前置链路新增统一权限校验模块，基于当前运行模式判断操作合法性，从底层杜绝模式越权；所有工具调用必须经过该校验层，确保权限管控无遗漏。

### 验收标准

- 对话模式下，可正常通过 @ 引用、右键注入等方式读取工作区及本地任意路径文件，并基于文件内容正确作答；
- 对话模式下，所有文件修改、终端执行类操作均被拦截，并有明确的提示信息，无越权执行风险；
- 智能体模式下所有原有功能正常运行，文件读写、终端执行、安全模式切换等能力无回归问题；
- 模式切换即时生效，权限规则同步切换，无缓存残留。

## 二、核心功能全量回归校验（P0 必做）

### 问题背景

权限逻辑属于插件底层核心链路，修改存在波及其他关联功能的风险，需执行全覆盖回归验证，避免引入非预期缺陷。

### 需求描述

完成权限逻辑修改后，对核心功能链路执行全量回归校验，确保修改不影响其余已稳定功能：

1. **校验范围**：智能体模式完整执行链路、上下文管理与 Token 统计、历史会话读写、编辑器高亮联动、全局设置项配置、多模型切换、安全权限模式切换、对话滚动交互。
2. **校验标准**：所有功能表现与 V0.8.0 版本完全一致，无功能失效、交互异常、样式错乱、数据统计错误等问题。
3. **问题闭环**：若校验中发现关联功能异常，同步修复并记录变更，确保版本交付质量。

### 验收标准

- 所有核心功能无回归问题，不会产生负优化；
- 权限修改仅作用于对话模式的能力边界，不波及其他模块逻辑。
